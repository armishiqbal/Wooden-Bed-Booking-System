# Wooden Bed Booking System  A web-based application developed using Django and Django REST Framework for managing wooden bed bookings and reservations efficiently.  ## Features  * Customer booking management * Add, edit, view, and delete bookings (CRUD operations) * Bed management system * Django Admin Panel * REST API endpoints * Form validation and database integration * Responsive user interface  ## Technologies Used  * Python * Django * Django REST Framework (DRF) * SQLite3 * HTML5 * CSS3 * Bootstrap * JavaScript * Django Templates * Django Forms * Django ORM * REST APIs * MVT Architecture  ## Installation  1. Clone the repository. 2. Install dependencies:     ```bash    pip install -r requirements.txt    ``` 3. Apply migrations:     ```bash    python manage.py migrate    ``` 4. Run the server:     ```bash    python manage.py runserver    ``` 5. Open:     ```    http://127.0.0.1:8000/      Armish Iqbal BS Computer Science Student
